# Projeto Frontend - Experiência Prática 4

## Sobre o Projeto
Apresentação geral da aplicação desenvolvida, detalhando o objetivo técnico e as tecnologias base adotadas, como HTML5 Semântico e CSS3.

## Acessibilidade e WCAG 2.1
Projeto com navegação por teclado, uso correto de atributos ARIA e contraste visual em conformidade com o Nível AA.

## Como Executar o Projeto
1. Clone o repositório: `git clone [URL]`
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
